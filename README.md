## 🗂️ هيكلية الصفحات المستقلة
1. **الرئيسية (`index.html`):** نظرة عامة مختصرة، بيانات الاعتماد المهني، بطاقات بوابات الأقسام الرئيسية، وأزرار التواصل المباشر السريعة.
2. **المشاريع الهندسية (`engineering.html`):** السجل المهني الحقيقي للمشاريع المنجزة مع مؤسسة مساكن الجزيرة للمقاولات والجهات الحكومية (مكتب وزارة الصحة، جمعية عزم، سكن طلاب كليات الراجحي، تأهيل مدخل بريدة، ترميم الابتدائية 193، وغيرها).
3. **مكتبة ليسبات الأوتوكاد (`lisps.html`):** صفحة مستقلة لليسبات المستخرجة من مجلد `D:\ذكاء\ليسبات` وملف `amer.pdf` (مثل: `AL3MERLG`, `DimTable`, `asd`, `BlockManager`, `CAD2MAP`, `TEXTCOUNT`, `cb`, `cnt`, `TPL`, `LAM`, `FLA`, `TE`, `TL`) مع إرشادات التشغيل عبر `APPLOAD` وأوامر التشغيل.
4. **نسخ الويندوز المعدلة (`windows.html`):** نسخ ويندوز 11 (26H2) متعددة اللغات بدون متطلبات وبدون حساب، ويندوز 10 للمهندسين، ويندوز 2026، وأدوات الترقية والإصلاح.
5. **البرامج ومشاريع GitHub (`programs.html`):** حزمة ADDON-AUTOCAD، أداة pro3mer، برامج Foxit و PDF-XChange الصامتة، تعريب FxSound و mpc-qt، وأدوات الصيانة وتفعيل الأوفيس والأنظمة.
6. **قنوات التليجرام (`telegram.html`):** روابط القنوات والمجتمعات من وثيقة `amer.pdf` وقناة البرامج الهندسية `@pro3mer`.
7. **المقالات والشروحات (`articles.html`):** المواضيع الحقيقية المنشورة في منتديات الشارقة سوفت، المشاغب، وزيزووم، مع قارئ مقالات فوري.
